# Дашборд — Android-приложение (v1.0)

Оболочка для дашбордов команд (Google Apps Script). Все данные по-прежнему берутся из Google Таблиц:
приложение показывает тот же сайт, что и браузер, только в отдельном окне.

## Как получить APK
1. Любое изменение в репозитории → GitHub сам собирает приложение (вкладка **Actions**, ~5 минут).
2. Готовый файл — во вкладке **Releases**: `Dashboard_v1.0.apk`.
   Прямая ссылка на последнюю версию: `https://github.com/bagzik89/-/releases/latest/download/Dashboard.apk`

## Ссылки на дашборды
Файл `app/src/main/assets/dashboards.json`. Вставьте ссылки `/exec` — тогда сотрудникам ничего вводить не придётся.
Если ссылка пустая, приложение попросит вставить её при первом открытии (запоминает).

## Новая версия оболочки
Нужна только при смене иконки, названия или списка дашбордов. Увеличьте `appVersionName` и `appVersionCode`
в `app/build.gradle.kts` — установится поверх старой без удаления.
Обновления самих дашбордов (Code.gs / Index.html) пересборки не требуют.

## Важно
- Ключ подписи `keystore/release.jks` не удаляйте и не меняйте: иначе новая версия не установится поверх старой.
- Развёртывание Apps Script должно иметь доступ «Все» (Anyone) — вход через аккаунт Google внутри приложений Google блокирует.
