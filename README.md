# Дашборд — Android-приложение (v1.0)

Оболочка для дашбордов команд (Google Apps Script). Все данные по-прежнему берутся из Google Таблиц:
приложение показывает тот же сайт, что и браузер, только в отдельном окне.

## Как получить APK
1. Любое изменение в репозитории → GitHub сам собирает приложение (вкладка **Actions**, ~5 минут).
2. Готовый файл — во вкладке **Releases**: `Dashboard_v1.0.apk`.
   Прямая ссылка на последнюю версию: `https://github.com/bagzik89/-/releases/latest/download/Dashboard.apk`

## Ссылки на дашборды
Файл `app/src/main/assets/dashboards.json`. Вставьте ссылки `/exec` — тогда сотрудникам ничего вводить не придётся.
Если ссылка пустая, приложение попросит вставить её при первом открытии (запоминает).

## Новая версия оболочки
Нужна только при смене иконки, названия или списка дашбордов. Увеличьте `appVersionName` и `appVersionCode`
в `app/build.gradle.kts` — установится поверх старой без удаления.
Обновления самих дашбордов (Code.gs / Index.html) пересборки не требуют.

## Важно
- Ключ подписи `keystore/release.jks` не удаляйте и не меняйте: иначе новая версия не установится поверх старой.
- Развёртывание Apps Script должно иметь доступ «Все» (Anyone) — вход через аккаунт Google внутри приложений Google блокирует.

# Перерывы — Android-приложение (v1.0)

Отдельное приложение для сотрудников и супервайзеров: сайт «Расписание перерывов» в своём окне + уведомления телефона.
Модуль `breaks/`, собирается тем же GitHub Actions вместе с «Дашбордом».

## Как получить APK
Вкладка **Releases** → «Перерывы breaks-v1.0» → `Breaks.apk`.
Прямая ссылка: `https://github.com/bagzik89/-/releases/download/breaks-v1.0/Breaks.apk`

## Что умеет
- Открывает сайт «Расписание перерывов» (вход по логину и паролю сайта, вход запоминается).
- Напоминания в телефон о своих перерывах: **за 5 минут** и **в начало** перерыва — даже если приложение закрыто
  (ставятся при каждом открытии сайта и переставляются при изменении графика).
- Уведомления сайта (заявки на обмен, ответ коллеги, решение руководителя) — пока приложение открыто или свёрнуто.
- «Назад» на главной: обновить, изменить ссылку на сайт, свернуть.

## Ссылка на сайт
`breaks/src/main/assets/breaks.json` → `url`: ссылка `/exec` из Apps Script. Пусто — приложение спросит её при первом запуске.

## Новая версия
Увеличьте `appVersionName` и `appVersionCode` в `breaks/build.gradle.kts`. Обновления сайта (Code.gs / Scripts) пересборки не требуют.
Мост к телефону (`window.BreaksApp`) поддерживается сайтом начиная с версии 2.8.1-dev.
